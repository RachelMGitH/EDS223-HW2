## Data Access
The data is sourced from:

1. The United States Environmental Protection Agency’s previous EJScreen: Environmental Justice Screening and Mapping Tool, and can be accessed from the following link: [link](https://drive.google.com/file/d/1nG6Nj1bXfzQFOVMO8Km3eNy4SWu1YcIQ/view)

3. The Statewide Integrated Traffice Records System (SWITRS) [link](https://tims.berkeley.edu/)
